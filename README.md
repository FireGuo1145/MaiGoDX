# MaiGoDX

A lightweight, high-performance maimai DX game server backend rewritten in **Go**, inspired by [AquaDX](https://github.com/MewoLab/AquaDX).

## Features

- Written in clean and efficient Go (Golang).
- Multi-file modular project structure (Controllers, Handlers, Models, Middlewares).
- Native support for Zlib compression/decompression for ALL.Net protocol.
- Compatible with maimai DX client requests (`/g/SDGA/...` and `/g/SDEZ/...`).

## Getting Started

```bash
cd cmd/server
go run main.go
```
